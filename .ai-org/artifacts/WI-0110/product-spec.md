# WI-0110 product specification

## Outcome

Produce the first complete, auditable Wave 5A mechanism result—or a truthful fail-closed record—without purchasing Credits or weakening the frozen comparison protocol.

## Acceptance

1. The WI-0109 replay suite and fresh installed-schema preflight pass before generation.
2. A new lab is created without replacing either retained failed-run lab.
3. At most four candidates run sequentially with GPT-5.6 Luna and Max reasoning.
4. Each completed turn records exact Provider Token telemetry, timing, baseline and candidate revision, bounded changed paths, public and held-out test results, and one blind package.
5. Any permission request, reroute, missing usage, protocol violation, out-of-scope write, dirty candidate, hard limit, interrupted terminal, or ambiguous state stops the program without retry.
6. The result makes no causal savings, Temple superiority, billing, model-routing, production, or enterprise-readiness claim.

## Excluded

Purchased Credits, automatic Credit reload, API-key billing, usage resets, fallback models, network access, dependency installation, external writes, deployment, publication, release, automatic routing, and Wave 5B or 5C qualification.
