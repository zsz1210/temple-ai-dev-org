# Model-facing context representation

The user approved separating model-readable material from machine validation metadata, followed by a bounded comparison after verification. WI-0213 implements the representation; live execution needs a frozen successor protocol, current account preflight and a configured budget. No reset, purchase, refill, retry, release or publication is implied.

Add optional `context enter --format model` (still `--no-write --json`). Default `--format full` remains byte-compatible. Both formats execute exactly the same acquisition, source validation and freshness checks. The model view is derived JSON, never lifecycle authority. Keep complete source bodies, source/body hashes, reasons, projection labels and selection restrictions. Keep the complete semantic entry, navigation, warnings, coverage and reuse decisions. Remove only the repeated acquisition source rows and source-manifest measurement fields. Preserve binding identity, digests, authority paths, unselected reference paths and categories. Do not perform model summarization, write caches, or change source selection. Unknown schema, incomplete acquisition, warnings or recovery return the original full object. CLI exit status remains based on the original result. Full machine metadata is retained in the acquired in-memory object; it is not persisted. Running full format again reacquires and may observe newer inputs.

Acceptance: default output unchanged; all required body strings and semantic fields equal the acquired object; input not mutated; full diagnostics on fallback; unexpected schema/metadata uses full output; source delimiters cannot affect JSON structure; invalid format rejected before acquisition; expected-plan rejection identical; installed CLI read-only tests and full verification pass. Measure complete encoded output as well as body bytes; no Token savings claim from bytes. Compare identical tasks/models with only representation changed after freezing the candidate, not against an old prompt as a causal control.

Risk: hiding a future semantic field could remove a safety instruction. Use strict top-level key sets for every object whose fields are omitted; preserve nested semantic objects whole. Extra keys trigger full fallback. Do not reinterpret unknown objects. Rollback removes the optional renderer and CLI switch, leaving default behavior intact.

Coordination: WI-0190 and WI-0211 overlap broad test/src roots but are retained release-gate records with released claims; this successor starts from their merged main state. Their evidence and implementation revisions stay frozen. WI-0212's shared prompt repair is already merged and stays unchanged in this implementation.

Implementation placement: use `src/context-enter.mjs`, `src/cli.mjs` and `test/context-enter.test.mjs`; no separate renderer module or new test file is needed. This replaces the initially reserved module path without changing behavior scope. The existing CLI cannot update affected paths through configure; this design records the exact adjustment rather than manually editing canonical JSON. Keeping the small pure renderer beside its producer preserves the reviewed package file-count boundary. The same WI-0211 src overlap resolution applies.
