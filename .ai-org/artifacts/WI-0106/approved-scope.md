# WI-0106 approved scope

The repository owner authorized the next validation-program design after Wave 4. This Work Item defines Wave 5 and performs only read-only research, local arithmetic, repository documentation, and lifecycle recording.

## Included

- Separate a Temple-versus-minimal process comparison from a model-profile comparison.
- Define matched fixtures, controls, quality grading, measurements, ordering, telemetry prerequisites, stop rules, and follow-on decisions.
- Derive a small feasibility-pilot envelope from retained Temple observations and current official OpenAI documentation.
- State exactly what must be approved before a model-backed run.

## Excluded

- model generation or creation of live Codex evaluation tasks;
- purchase or automatic reload of Credits;
- external writes other than the separately governed repository pull-request workflow;
- public, production, company-data, deployment, release, or publication actions;
- automatic routing or mutation of `.ai-org/project/usage-policy.json`;
- resumption or reinterpretation of the stopped `WI-0067` manifest.

The design stops at a reviewable execution proposal. A later Work Item must receive explicit approval for the exact model turns and resource envelope.
