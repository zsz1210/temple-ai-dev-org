# WI-0164 Product Direction

## Qualification question

Can the exact Alpha.30 source candidate be packaged once, identified unambiguously, and used by a clean Node.js 24 project through Temple's deterministic AI-assisted setup path without hidden maintainer state?

## User-visible success

A prospective Alpha user can receive the source-built archive, install it without npm-registry availability, initialize a repository, repeat initialization safely, and use the installed project launcher, status, and Doctor. The retained record makes it possible to identify exactly which archive was tested.

## Evidence hierarchy

Correctness and identity come first: exact source revision, one tarball digest, complete manifest, clean consumer, full behavior, browser presentation, and public-surface review. Timings and sizes are descriptive diagnostics, not performance or productivity claims.

## Product boundary

This qualification answers whether the frozen artifact works as described. It does not answer whether Temple improves every project, whether automatic routing is safe, whether enterprises are qualified, or whether the repository and package should now be published.
