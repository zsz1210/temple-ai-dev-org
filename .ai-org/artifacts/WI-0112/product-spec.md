# WI-0112 product specification

## Outcome

Produce the first complete, auditable Wave 5A mechanism result—or another truthful fail-closed record—without redeeming a usage reset, purchasing Credits, or weakening the frozen comparison protocol.

## Acceptance

1. The merged WI-0111 quote-aware replay suite and fresh installed-schema preflight pass before generation.
2. A new `r4` lab is created without replacing any retained failed-run lab.
3. At most four candidates run sequentially with GPT-5.6 Luna and Max reasoning.
4. Each completed turn records exact Provider Token telemetry, timing, baseline and candidate revision, bounded changed paths, public and held-out test results, and one blind package.
5. Any permission request, reroute, missing usage, protocol violation, out-of-scope write, dirty candidate, hard limit, interrupted terminal, or ambiguous state stops the program without retry.
6. The result makes no causal savings, Temple superiority, billing, model-routing, production, or enterprise-readiness claim.

## Excluded

Usage-reset redemption, purchased Credits, automatic Credit reload, API-key billing, fallback models, network access, dependency installation, external writes, deployment, publication, release, automatic routing, and Wave 5B or 5C qualification.
