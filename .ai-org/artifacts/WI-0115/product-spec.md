# Product specification — WI-0115

## Outcome

A maintainer can tell whether a fresh Temple installation gives an Agent a safe, usable next-step contract without confusing installed files with loaded instructions or granted authority.

## Acceptance

- A package-created clean repository completes init, installed-launcher Doctor, and read-only Status.
- The init result names the canonical instruction sources and keeps session loading, comprehension, lifecycle authority, mutation authority, external-write authority, and spend authority false.
- The absent-file Claude path creates only the documented `@AGENTS.md` import and leaves that project-owned file outside managed ownership.
- Timings, command outcomes, declared sources, actual deterministic reads, and provider-observation availability are retained separately.
- The sample repository is disposable and no follow-on feature development occurs.
