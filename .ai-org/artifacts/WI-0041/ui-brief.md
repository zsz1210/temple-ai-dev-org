# UI design brief — WI-0041

- Delivery mode: `code-first`
- Surface: existing local and private read-only Dashboard
- Visual change: none intended
- Required states: loading, current, and stale remain visually distinct
- Runtime review: desktop 1440 × 1000 and narrow 420 × 900
- Acceptance: the Usage & models content remains readable, no horizontal page overflow appears, and the current-state banner replaces the stale warning after replay settles

This brief does not introduce a design-vendor dependency or authorize changes to remote command availability.
