# Delivery path audit before measurement

The frozen B/C treatment has three different costs. Entry acquires governing material; claim and finish record ownership/lifecycle; product implementation and fresh verification remain real work. Fewer administrative commands alone do not demonstrate fewer model turns, fewer Tokens or lower total elapsed time.

Potential remaining duplication: mandatory cold reads of AGENTS.md and TEMPLE.md coexist with the entry packet's whole required material. The v8 subject instruction allows reuse of actually available unchanged bodies but does not waive native instructions or remove packet bodies. Returned packet bytes can therefore still overlap earlier reads. This experiment measures the current implemented entry, not a hypothetical deduplicated instruction loader.

Finish includes full Status/Doctor; the subject is explicitly told not to repeat successful current checks solely for administrative completion. An observed later repeat is recorded by command hash but is not automatically classified as wasted: changed state or a failed receipt can justify it. Entry fallback and diagnostic failure remain visible. Setup now supplies the explicit local-only repository integration policy, fixing a fixture omission rather than suppressing a warning.

The pure-function task has a clear contract and an ordinary fresh verifier. It is an overhead screen with limited headroom for correctness gains. Recovery, evolving requirements, multiple writers and high-risk delivery are excluded; no positive result here would establish their benefits, and a negative result would not quantify them. The next improvement should follow measured stage/operation costs, not the number of organizational roles or document files.

No rule, core guard or workflow profile was removed during this measurement work.
