Complete user-approved steps 2 and 3 after WI-0206: distinguish mechanical validation from model reading, index historical-only evidence, and remove avoidable instruction-induced work. No model comparison, authority downgrade, Independent QA removal, package publication or external release.

## Selection contract

Add opt-in `context enter --material task`; default `stage` remains unchanged. All source acquisition, path safety, digest and actor checks run on full sources before projection. The task projection is a derived view, not replacement authority.

1. Preserve full instruction, policy, workflow, collaboration, usage, approved scope, specification, design and current handoff material.
2. Select complete actor and assignment records only from recognized exact inventory shapes. Include the requested actor, recorded actor, current/handoff/next Positions and all assigned actors for those Positions. Preserve every field of retained records. Unknown schema/record shapes, recovery, explicit independent route/specification/gate requirements, missing actor relations or a representation that is not smaller retain the full source.
3. Index only evidence referenced exclusively by known earlier assurance gates (`evaluation_report`, `independent_qa_pass`, `release_record`) while in Build/Test, and not required by the current edge. Keep path, digest, size and gate reasons, mark the omitted body as historical context that cannot satisfy a current gate. Any other source reason retains its body. Approval, scope, acceptance, risk and developer evidence never enter this rule. Unknown gate categories remain full sources.
4. Keep safety validation on all selected original sources, including indexed evidence. Missing/unsafe sources still fail. Source and representation digests bind changes. No selected source is silently truncated.

Caller availability from WI-0206 remains separately opt-in. A task projection cannot be misrepresented as an already-read whole source. Defaults remain compatible; task packets have their own explicit schema version and measurements.
