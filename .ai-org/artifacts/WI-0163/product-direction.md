# Alpha.30 Product Direction

## Intended reader

An individual developer, a multidisciplinary team, or an organization evaluating a repository-native operating layer for AI-assisted development.

## Supported claim

Temple is a repository-native, human-directed operating framework for organizing AI-assisted development with durable Work Items, explicit responsibilities, evidence gates, recovery, learning, and explainable advisory execution routing.

The claim is supported by the shipped framework contracts, current test suite, clean-room AI-assisted path, multi-repository rehearsals, privacy review, and Independent QA records. It describes available operating capability, not universal outcome improvement.

## Explicit non-claims

- No guaranteed Token, cost, latency, or productivity savings.
- No automatic model selection or Provider execution.
- No production, regulated, enterprise-wide, or broad multi-company qualification.
- No claim that an unaided first-time human can operate Temple without AI assistance.
- No requirement to install the optional Management Console, Usage Collector, semantic retrieval, or other optional integrations.

## Proposed distribution boundary

The first public Alpha remains source-first through GitHub. npm stays deferred. Version identity, visibility, tag, GitHub Release, npm, and announcement remain separately approved actions.

## Version choice

Use `0.1.0-alpha.30` because the repository has changed materially since the Alpha.29 candidate: adaptive execution foundations, staged context routing, multi-repository validation, lifecycle-evidence hardening, clean-room AI-assisted onboarding, and publication-surface normalization are now present. The version remains prerelease and makes no stability promise beyond its documented Alpha boundary.
