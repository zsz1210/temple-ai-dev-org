# WI-0163 Approved Scope

The repository owner approved `0.1.0-alpha.30` as the next narrow source-first Alpha candidate and accepted the following claim boundary:

> Temple is a repository-native, human-directed operating framework for organizing AI-assisted development with durable Work Items, explicit responsibilities, evidence gates, recovery, learning, and explainable advisory execution routing.

The candidate must explicitly avoid claiming universal efficiency or Token savings, automatic model routing, enterprise or regulated qualification, or a mandatory Management Console.

This approval authorizes the bounded candidate-freeze changes and lifecycle evidence in WI-0163. It does not authorize repository publication, a visibility change, a tag, a GitHub Release, npm publication, deployment, or an announcement.
