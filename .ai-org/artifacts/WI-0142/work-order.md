# WI-0142 work order

## Outcome

Repair the two measurement weaknesses exposed by WI-0141 and retain a reusable method for future Temple process and model comparisons.

## Authorized slice

- recognize privacy-safe reads of the condition-local control package from supported sanitized Codex App Server action shapes;
- keep ambiguous, unsafe, oversized, or escaping acquisition records classified as `unknown`;
- expose gross input, cached input, non-cached input, output, Operational Tokens, cache share, and repetition spread as separate measurements;
- report whether cache control is sufficient for a causal efficiency claim instead of inferring validity from a favorable average;
- add a human-facing evaluation guide and a copyable draft protocol template for later workflow and model comparisons;
- update documentation navigation so maintainers can find the retained method.

## Boundaries

This Work Item is deterministic and generation-free. It does not rewrite any WI-0141 artifact, run a model comparison, approve a new model, set a universal repetition count, publish, release, deploy, or authorize external spend.
