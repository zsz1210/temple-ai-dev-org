# Risk review - WI-0135

## Risks and controls

- **Unapproved consumption:** exact digest-bound approval permits existing Pro allowance only; purchased Credits, automatic refill, and usage reset are false.
- **Protocol drift:** setup and preflight compare protocol, fixture, instruction, tool-policy, CLI, and App Server schema digests before generation.
- **Duplicate consumption:** the runner refuses any lab containing a prior run result or observation stream; retries and fallback are zero.
- **Model substitution:** requested and acknowledged models must match and any reroute interrupts the turn.
- **Data or network escape:** candidates use workspace-write isolation with network disabled and an allowlisted command policy; the evaluator is read-only with tools forbidden.
- **Quality gaming:** held-out tests are coordinator-owned and the evaluator receives arm-neutral packages before the mapping is unsealed.
- **Misleading claims:** the sample is two bounded implementation cases, cannot establish statistical superiority, and cannot authorize routing changes.
- **Repository bloat or sensitive retention:** the lab and raw Provider content remain outside Git; only normalized bounded evidence is retained.

## Residual risk

The Provider reports detailed usage but not monetary cost or effective turn reasoning effort. Four candidates can confirm this exact treatment on these exact cases only. Random model variance, evaluator variance, order effects, and task-family selection remain material limitations.
