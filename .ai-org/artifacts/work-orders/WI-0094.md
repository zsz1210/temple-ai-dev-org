# WI-0094 work order

## Outcome

Keep the optional Management Console responsive as retained Temple evidence grows. The browser projection must include the human-facing summaries it renders, but it must not transfer duplicate evidence bodies or retained Provider task histories that the Console never displays.

## Measured baseline

The representative repository at `d29fa5a` contains 101 Work Items, 345 evidence records, two detailed Usage observations, and 6,145,329 bytes of retained telemetry archives.

- Usage-only report: 13,291-byte compact payload; 79.454 ms first read; 27.188 ms warm median; 43.592 ms warm p95 over 20 repetitions.
- Optional Console with caching disabled: 2,077,930-byte HTTP response; 1,010.913 ms first request; 889.559 ms warm median; 1,073.562 ms warm p95 over 10 repetitions.
- Optional Console cache hit: 9.384–10.946 ms over nine repeated requests.
- Idle optional Console process after loading: 35,488 KiB resident memory and 0.0% sampled CPU.
- Historical pre-split evidence recorded approximately 38.294 seconds and 1.864 MB. The current split architecture has already removed the tens-of-seconds latency, but not the oversized viewer payload.

The raw observation is retained in `.ai-org/artifacts/WI-0094/baseline-observation.json`.

## Approved target

These are bounded regression targets for this repository and machine class, not universal product guarantees:

- keep the Usage-only warm p95 at or below 60 ms and its compact JSON payload at or below 16 KiB;
- keep an unchanged cached Console request p95 at or below 25 ms;
- keep an invalidated Console rebuild p95 at or below 1.5 seconds;
- reduce the human Console HTTP snapshot to at most 512 KiB for the representative repository;
- preserve deterministic visibility of new canonical and retained Usage observations after invalidation.

## Product boundary

The Console remains optional and read-only. Usage collection remains a separate optional process. The change does not alter canonical evidence, telemetry retention, privacy redaction, lifecycle authority, model routing, or the Provider trust work retained by WI-0033.

## Acceptance

The acceptance criteria in `.ai-org/work-items/WI-0094.json` govern delivery. The candidate must include structural regression tests, the full repository verification suite, live measurements at the exact candidate revision, and Independent QA by an Agent Identity other than the Developer.
