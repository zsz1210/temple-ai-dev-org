## Command contract

- `backup set-inspect [target] --root directory [--json]`
- `backup retention-preview [target] --root directory --minimum-to-keep N [--preserve name] [--json]`
- `backup retention-apply [target] --root directory --minimum-to-keep N [--preserve name] --expected-plan digest --confirm-delete [--json]`

- `federation validate [target] [--json]`

Repeatable options are `--preserve`, `--event-type`, and `--redact-key`. Integers must be explicitly bounded. Retention apply must require the preview digest and `--confirm-delete`. Portfolio build may write only `.ai-org/views/portfolio.json` in the coordinator; `--no-write` must remain read-only. No participant repository or lifecycle state may be mutated.

## Verification

Focused tests must cover parsing, JSON and human output, retention consent and stale digest behavior, audit export creation/refusal, federation validation, portfolio no-write/write boundaries, and participant hash stability. Run full verification and diff checks.

## Risk review and rollback
