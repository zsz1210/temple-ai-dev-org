# WI-0101 work order

## User decision

The Management Console is optional. When explicitly started on loopback it must present itself as a local read-only view, not as a private-network viewer and not as an Agent command surface.

## Scope and acceptance

The canonical scope and three acceptance criteria are recorded in `.ai-org/work-items/WI-0101.json`. Preserve the approved Management Console layout, navigation, responsive behavior, theme, and private-viewer redaction. Change only the access-mode presentation required by the separated server and the managed-service regression contract.

## Stop boundary

Stop when the local read-only mode is truthful at runtime and the managed service is proven Collector-only. Do not redesign screens, add remote commands, or change the Console information architecture.
