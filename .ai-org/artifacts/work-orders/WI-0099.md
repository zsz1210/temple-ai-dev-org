# WI-0099 work order

## User decision

The active Temple support floor changes to Node.js 24. Full integration and Management Console browser verification run locally. GitHub Actions remains a bounded remote repository guard because the repository owner's hosted Actions resources are limited.

## Scope

- remove Node.js 22 from active package, bootstrap, README, roadmap, release-readiness, and CI claims;
- require Node.js 24 or later while identifying Node.js 24 as the remotely verified baseline;
- replace the two-job hosted matrix and ordinary hosted full/browser suites with one Node.js 24 job capped at five minutes;
- retain local `npm run verify` as the complete behavioral gate and local `npm run test:browser` for user-interface changes;
- preserve historical Alpha.29 and earlier evidence as records of what actually ran at those revisions.

## Acceptance

The acceptance criteria are the three canonical criteria in `.ai-org/work-items/WI-0099.json`. CI contract tests must fail if a Node.js matrix, Node.js 22, `npm run test:full`, or `npm run test:browser` returns to the ordinary hosted workflow.

## Boundaries

- Do not change repository visibility, branch protection, billing settings, releases, tags, npm publication, or other GitHub settings.
- Do not weaken the local full verification command.
- Do not rewrite historical evidence to imply that old runs used the new policy.
- Preserve the adaptive-onboarding changes already present in WI-0097 and WI-0098.
