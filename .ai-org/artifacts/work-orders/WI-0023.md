# Work order — WI-0023

## Purpose

Close the second WI-0022 Independent QA no-go: local Git replacement refs must never remap an expected federation revision.

## Design and risk review

- Set `GIT_NO_REPLACE_OBJECTS=1` for every federation Git subprocess, including HEAD, status, tree, and blob operations.
- Add the exact attack: expected A, replacement B, HEAD A, working tree reset to B, scoped status apparently clean under replacement semantics.
- Prove literal expected-revision content is used or the participant becomes unknown; replacement content must never be projected under A.
- Preserve local read-only operation, bounded subprocesses, and the explicit lack of remote attestation or distributed locking.
