- Portfolio generation writes only the generated coordinator view and never a participant repository.

- Version and capability claims must match shipped code and passing tests.

- A fresh initialized fixture and an upgraded older fixture expose identical supported contracts while preserving project-owned content.
- `npm run verify`, `git diff --check`, and Doctor pass at the exact candidate revision.
