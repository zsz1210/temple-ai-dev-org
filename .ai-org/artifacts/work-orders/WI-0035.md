# Work order — WI-0035

## Purpose

Reduce redundant private-repository CI minutes while keeping governance and product-behavior evidence separately visible and fail closed.

## Technical design

- Select scope before expensive verification and classify documentation-only, strict evidence/state-only, and behavioral changes.
- Keep one GitHub job to avoid per-job minute rounding, but run governance and behavioral commands as separately named steps whose outcomes are aggregated with `if: always()`.
- A governance failure must not suppress the behavioral result; the final job must still fail if either required lane fails.
- Evidence/state-only scope uses a narrow allowlist and runs repository checks, fast contract tests, schema, Doctor, and focused evidence/status tests.
- Any executable, schema, workflow, package, test, script, rename/copy endpoint, deletion, mode change, comparison failure, or unknown path selects full verification.

## Verification

Add adversarial scope fixtures for both sides of renames/copies, executable-to-Markdown changes, deletion, workflow/package/schema changes, lifecycle-only changes, and unavailable comparisons. Measure local lane timing and retain release-only full verification.
