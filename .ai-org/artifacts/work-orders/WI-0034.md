# Work order — WI-0034

## Purpose

Make the local Dashboard reliable as an operational surface instead of a long audit ledger that can discard user input or obscure current attention.

## Technical design

- Preserve dirty command form text, selection, focus, and local preview across unrelated snapshot/SSE refreshes.
- When the selected target or active-turn precondition changes, retain the draft, clear confirmation, and require an explicit review with a visible stale-target explanation.
- Separate stream connectivity from snapshot freshness and disable mutations against a stale snapshot.
- Present current attention, executing/QA/approval states, and current Work Items before collapsed terminal history.
- Deduplicate repository-origin timeline observations and retain canonical occurrence time and provenance.

## Verification

Exercise unrelated and target-changing SSE refreshes, snapshot failure, canonical attention, failed workers, terminal history, duplicate repository events, desktop, 420-pixel layout, keyboard focus, and dynamic status announcements with a deterministic local provider only.
