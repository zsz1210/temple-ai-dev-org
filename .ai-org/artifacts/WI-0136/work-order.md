# WI-0136 work order

## Outcome

Produce one reproducible, fail-closed comparison between a competent minimal responsible workflow and Temple for the same four-repository microservice change. The experiment must explain whether Temple changes delivery outcomes enough to justify its coordination and context overhead.

## Authorized work

- Replace the placeholder repository revisions in the WI-0118 rehearsal with deterministic local Git repositories and exact source digests.
- Implement and test a no-generation fixture builder, protocol validator, live runner, blind evaluator package, and result analyzer.
- Measure cold recovery, task-boundary conflicts, contract convergence, correctness, rework, Human intervention, Provider usage, latency, and artifact footprint.
- Run the live model-backed comparison only after a final preflight publishes the exact protocol digest and bounded account envelope and the Human Principal approves that exact envelope.
- Preserve a stopped or negative result without retry, fallback, reroute, or hidden correction.

## Fairness boundary

The minimal-responsible arm is intentionally competent. It receives clear scope, owners, version control, tests, review expectations, and an integration decision. Both arms receive the same frozen source repositories, task, public and hidden tests, tool policy, and model route. The treatment difference is Temple's repository-backed organizational mechanism.

## Stop condition

The Work Item ends after one frozen matched run is analyzed, independently checked, and reported. It does not authorize routing-policy changes, statistical generalization, Temple publication or release, service deployment, Credits purchase, automatic refill, reset redemption, retry, fallback, or follow-on product work.

## Initial execution boundary

Local fixture, validation, and no-generation preflight work is authorized now. Provider generation remains pending an exact later approval record.
