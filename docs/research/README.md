# Research

Research records preserve primary-source investigation that informed a possible framework decision. They are inputs, not accepted architecture or shipped capability claims. An accepted direction must be recorded in an ADR, and implemented behavior must be supported by code, tests, and bounded validation evidence.

- [Phase 3 control-plane research](phase-3-control-plane-research.md) — event transport, provider boundaries, live observation, authority separation, and retained risks considered before the Phase 3 design.
